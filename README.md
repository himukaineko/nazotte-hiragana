# なぞってひらがな

指でなぞって、ひらがなの書き順を練習する子ども向けアプリです。スマホ・タブレットのブラウザで動きます。

**https://himukaineko.github.io/nazotte-hiragana/**

## できること

- ひらがな46文字の なぞり書き(書き順・書く方向も判定)
- 「みないで」モード(お手本なしで、声を聞いて書く)
- ことばモード(36語で46文字すべてを練習)
- じぶんの ことば(保護者が名前などを追加。濁音・小さい字・「ー」も使えます。読み上げは端末の音声)
- がんばりカード(はなまる・ほしのスタンプ帳)
- 読み上げ音声、効果音
- iPad / iPhone のホーム画面に追加すると、アプリのように全画面で使え、オフラインでも動きます

## iPad で使うには

1. Safari で上のURLを開く
2. 共有ボタン → 「ホーム画面に追加」

記録はその端末のブラウザに保存されます。
